# 后室 · The Backrooms

## 当前版本更新说明

这是一个可以直接在浏览器运行的后室探索游戏，支持电脑、手机和 iPad，并加入了完整的多人房间功能。

### 多人联机

- 同一个网址可以创建或加入 6 位房间号。
- 单个房间最多 5 人，所有游玩模式都可以联机。
- 房主开始游戏后，全员同步倒计时、层级、地图种子和游戏模式。
- 游戏已经开始后，新玩家加入会直接进入当前房间和当前层级。
- 客机退出会立即释放房间名额，并向房间内玩家提示谁退出了。
- 新玩家加入、玩家死亡、连接断开等事件都会显示提示。
- 房主回到主页时房间不会立刻消失，只有点击“关闭联机”才会关闭房间。
- 房间内聊天是临时的，退出联机后不会保存。
- 解决了客机进不来、连接后卡住、重复传送到房主、不同模式分裂、房主独占怪物仇恨等问题。

### 玩家显示与同步

- 大厅采用“自己在前、队友在后”的组队站位。
- 每个玩家的名字都会显示在角色上方，房主名字使用黄色标识。
- 玩家自定义的防化服颜色会在大厅和游戏内同步；双方看到的颜色保持一致。
- 队友即使距离很远也能看到，并显示距离。
- 远程玩家位置使用插值和短时位置预判，减少卡顿和瞬移感。
- 怪物会把房间内的所有玩家纳入仇恨和攻击目标，不再只攻击房主。

### 聊天、语音与标记

- 电脑端按 T 打开聊天框，再按 T 可以关闭空的聊天框。
- 消息会像 Minecraft 一样短暂显示，过一段时间自动淡出，避免一直挡住画面。
- 手机和 iPad 增加聊天按钮，可以和电脑玩家正常互发消息。
- V 键或麦克风按钮控制语音，默认闭麦。
- G 键或手机“标记”按钮可以标记位置或物品，队友可以看到标记内容。
- 支持传送请求：电脑端按 P 打开队友列表，方向键选择，Enter 发送请求；对方按 Y 同意、N 拒绝。
- 手机和 iPad 可以直接点击传送按钮选择队友。

### 物品与背包

- 增加 10 格横向背包，格子紧密排列。
- 电脑端按 E 打开背包，手机和 iPad 使用左下角“背包”按钮。
- 支持拾取、丢弃和联机物资同步，物品被队友拿走后会从其他玩家画面消失。
- 增加手电筒，支持放入背包、使用和丢弃。
- 绿色杏仁水：短时间加速，恢复 10% 最大生命值和 5 点饱食度。
- 蓝色杏仁水：短时间加速、夜视，恢复 20% 最大生命值和 15 点饱食度，并恢复精神状态。
- 迁跃浆果改为随机前往另一张地图；联机时由房主决定目标，所有玩家一起传送。
- 享乐层出生区域增加可以通往 Level 0 的木门出口。

### 操作与移动

- 电脑端：WASD 移动、Space 跳跃、Shift 冲刺、F 使用、Q 丢弃、E 背包、G 标记、T 聊天、V 语音、F5 切换视角。
- 测试模式统一使用 Y 打开，避免和联机聊天的 T 冲突。
- 手机和 iPad 增加跳跃、急跑、标记、聊天、背包等触屏按钮。
- 手机和 iPad 的急跑改为点击一次切换，不需要一直按住。
- 手机和 iPad 可以单独调整右半屏转视角灵敏度，不影响电脑鼠标操作。
- 支持第一人称、第三人称和肩后视角切换。
- 第三人称镜头增加墙壁、地面和顶部碰撞限制，不会再穿墙或穿过天花板。

### 测试模式与管理命令

- 测试模式增加飞行开关。
- 飞行模式速度更快，可以穿墙；空格上升，Shift 下降。
- 联机聊天框输入 `这个你们自己猜嘿嘿` 后可以使用管理命令。
- `/gm 1` 开启创造模式：飞行、无限使用物品、生成怪物和在线切换层级。

### 画面与稳定性

- 手电筒光源会跟随玩家镜头，不会在换层后残留旧灯光。
- 夜视效果会正确作用到画面，并在效果结束后恢复正常。
- 修复远程角色偶尔只剩名字牌、模型消失、模型 NaN 位移和异步加载材质被错误销毁的问题。
- 修复多人移动、物品同步、怪物攻击、房间成员变化和连接重连相关的多项问题。

### 运行与部署

- 支持直接打开网页运行，也支持 Node.js 本地启动。
- 提供 Windows 启动脚本和局域网访问方式，局域网内的朋友可以使用同一个地址联机。
- 提供 Render 免费部署配置，使用 WebSocket 房间服务，不依赖浏览器本地文件打开方式。
- 发布前会自动生成 dist 静态目录，网页和房间接口由同一个服务提供。
